# Tiptoe the World — Auckland (Site 001/100)

Standalone static destination microsite.

## Netlify deployment
1. Netlify → Add new project → Import an existing project → GitHub.
2. Select `Muttanbal/tiptoe-the-world` and branch `main`.
3. Set **Base directory** to repository root (leave blank).
4. Leave **Build command** blank.
5. Set **Publish directory** to `sites/001-auckland`.
6. Deploy. Netlify serves `sites/001-auckland/index.html` as the homepage.

Use a **new Netlify site**, not the existing Tiptoe the World production deployment, to avoid changing its publishing directory.
